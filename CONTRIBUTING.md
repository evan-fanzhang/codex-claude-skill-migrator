# Contributing

## Development
1. Make changes in a feature branch.
2. Run migration script with `-DryRun` before real execution.
3. Validate any generated skill using `quick_validate.py`.

## Pull Requests
- Include a short problem statement.
- Include example command(s) used.
- Include before/after behavior.

## Security
Do not commit local absolute user paths, machine names, private tokens, or personal logs.
